# Aryan — handheld-style personal site

React + TypeScript + Vite. All content is in `src/data.ts`.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. In Vercel: **Add New → Project**, import the repo.
3. Vercel detects Vite automatically (build `npm run build`, output `dist`). Click **Deploy**.

Or from the CLI: `npx vercel` in this folder.

## Controls
Arrows / WASD move · Enter or Z opens · Esc or X goes back · tap works too.
